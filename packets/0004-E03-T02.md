## Context

This packet produces the single most valuable number in either initiative: **how long a
revoked agent keeps working.**

0000 claims revocation takes effect within one hour, enforced by `expires_at` on the export
rather than by convention. It has never been measured against a real consumer, because there
was no real consumer. There is now.

**Dependency:** T01 must be merged and 0000 must be publishing grants. The Check below names a
real subject and real URLs that do not exist until then — adjust to what is real and say what
you changed.

## Goal

A revoked grant stops working within the stated bound, measured against wall-clock time, and
the product keeps serving when 0000 is entirely unavailable.

## Boundary

**No changes to 0000.** If revocation does not behave as specified, that is a finding to
report, not a thing to patch from this side.

No new identity mechanism, no credential, no migration.

## Done when

- A grant is revoked in 0000 and published. **The session is refused within one hour**,
  measured, with the number recorded.
- **The refusal is distinguishable** from expiry, from an unknown principal, and from
  "packet not found".
- **The revoked grant is present in the published export as `state: revoked`**, not absent —
  fetch the real file and show it.
- **A grant that simply expires produces the same refusal** as one revoked, with no action
  taken by anyone.
- **The product serves with 0000 entirely unavailable**, from the last exports it holds, and
  states their age.
- **A stale grants export fails closed**: when it expires, the session is denied rather than
  granted on old evidence.

## Check

```bash
go test ./... && go vet ./...
```

Then the demonstration, which is the packet:

1. A live grant working: comment and transition succeed.
2. **Revoke it in 0000, publish, and time the refusal.** State the wall-clock number.
3. **Show the revoked grant in the fetched export**, `state: revoked`.
4. A grant left to **expire** → same refusal, nobody acting.
5. **Take 0000 offline entirely.** Show this product still serving, stating export age.
6. **Let the grants export go stale.** Show the session denied rather than allowed.

## Notes

**The measured number is the deliverable.** Report it even if it is worse than one hour —
especially then. A bound that is claimed and never measured is exactly the green-by-absence
pattern this organization keeps finding, and this is the packet that converts 0000's central
claim from a design statement into a measurement.

Never print a token.

Write `evidence/0004-E03-T02.md`. Its most important line is the number.
