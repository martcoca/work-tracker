only display, has a copy button, and is cleared when the component unmounts. The test created

credential id and metadata but no bearer display. No bearer value is included in this
evidence.

The list test verifies id, workload issuer and subject, packet, attempt, creation, expiry,
last use, active state, and revoked state. It begins with both active and already-revoked
metadata. Revoking the active row calls the human revoke route, changes that row to Revoked
and No action, keeps both rows visible, and performs no second list read.

The surface replaces route-level refusal text with these distinct actions:

- `workload_tenant_mismatch`: use a workload for the signed-in tenant;
- `invalid_workload`: enter an HTTPS issuer without query or fragment and a non-empty
