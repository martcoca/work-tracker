## Decisions and limits

The source policy is data attached to each configured export. `packets` is service-owned
and not required at startup; `tenant-directory` and `agent-grants` are not service-owned and
remain required. Only network unreachability or HTTP 404 can establish initial packet
absence. A successful HTTP response still has to pass the unchanged schema, freshness,
digest, provenance, and payload checks.

The empty state is a real snapshot built from the verified tenant directory with an empty
packet index; it is not a fabricated packet envelope or a bypass. Once a verified packet
copy exists, an unreachable refresh retains that last good copy and reports the refresh
failure as before. The packet, directory, and grants export contracts, configured URLs,
five-minute refresh interval, and five-second fetch timeout were not changed.

No cloud apply, deployment, publication, credential, real identity, or external export was
created or changed. A live Cloud Run redeploy was outside this packet's authority, so the
production startup that originally exposed the deadlock remains for the Founder to repeat
after merge.
