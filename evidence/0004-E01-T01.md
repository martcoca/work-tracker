## Decisions and limits

- The module is `github.com/martcoca/work-tracker`; the reusable domain API is one top-level
  `packet` package, while the repository-specific mutation executable is under `internal/`.
  This keeps deferred transports and persistence from becoming part of the model API.
- Status and closure are separate facts. Completion and supersession append close events;
  the superseded parent retains its prior status and exact body. `blocked` has no invented
  exit because the packet specifies none; `done` remains terminal.
- Supersession is one atomic append across parent and replacement streams. Versions count
  events, so multi-event operations advance by more than one.
- The model requires a tenant value but deliberately does not validate its directory
  membership or cross-packet relationship. It also does not authenticate actors, interpret
  scopes, validate body prose, persist events, serialize exports, or expose HTTP/UI; those
  responsibilities are explicitly above or beyond this packet.
- The packet links `../technical-spec.md`, but that file is absent from this repository.
  The packet itself supplied the complete frozen field list used here; the missing link was
  the only specification artifact that could not be verified.
