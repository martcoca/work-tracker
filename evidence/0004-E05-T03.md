directory without exactly one active tenant, imports every `packets/*.md` file through the
public packet model, and calls `packetexport.Publish`. It derives repository and full commit
provenance from Git. The importer represents repository `superseded` as the existing model
link and `superseded` closure, so it remains distinct from a `done` status and closure.

The deployment builds this export into `dist`, makes a preflight Hosting release, then runs
`verify-runtime-exports`, which now requires the live packet export as well as both external
authority exports. Firebase Hosting pins its Cloud Run rewrite, so a second release after
the guarded apply refreshes that pin to the newly deployed revision.
