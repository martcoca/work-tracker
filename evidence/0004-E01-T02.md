`sha256:ebac57f829546bb331ff7bd1a599657fecc4cc6ad38fb740dd69c1a8a91582b1`.

## Consumer procedure

A session receives `packets.json` as a local file; it does not call the tracker. It must:

1. Treat a missing file as no available packet export, distinct from invalid or stale data.
2. Require schema `martcoca.tracker.packets/1` and the exact six envelope fields.
3. Parse `published_at` and `expires_at`, require an exact one-hour interval, and refuse the
   whole export at or after `expires_at`.
4. Canonicalize the payload by recursively sorting object keys while retaining array order,
   compute its SHA-256 as `sha256:<lowercase hex>`, and compare it with `digest`.
5. Only after freshness and digest verification, decode the packet array and select work by
   tenant and packet id. Preserve each record's `version` for later optimistic writes.
6. Treat any verification failure as no usable export. Reading must never trigger a network
   request or fall back to a synchronous tracker call.

The tenant-directory input follows the same verification order with schema
`martcoca.identity.tenant-directory/1`. Its records exactly contain `id`, `slug`,
`display_name`, `status`, `created_at`, and `version`. The tracker rechecks directory
freshness when issuing and refuses absent and retired ids differently.

## Decisions and limits

The local publisher derives `source.repository` from git origin and `source.commit` from
HEAD, requires owner/name plus a full object id, and fails before creating output if either
fact is unavailable. Packet records sort by id before hashing; canonical JSON removes map
iteration order from the digest.

`suspended` is accepted because the packet names only unknown and retired tenants as issue
denials, while the 0000 contract defines suspended as a valid directory status. No policy
beyond the packet was invented.

No HTTP, cloud upload, object storage, credential, or real tenant was exercised; those are
outside this packet. Local atomic publication was tested in a temporary git repository,
including the no-output-on-provenance-failure case. The 0000 field table and its current
TypeScript contract were available locally and were compared directly; no contract field
was guessed.
