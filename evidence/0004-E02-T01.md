## Decisions

A static Vue shell is served from Firebase Hosting, but packet exports are not shipped to the
browser: doing so would expose other tenants' records even if the UI filtered them. A small
read-only Cloud Run service verifies the token and filters by tenant before constructing a
view. It holds the last verified packet export, the last verified 0000 tenant-directory
export, and cached public Google signing certificates. It exposes no mutating route and its
runtime service account has no project role grants.

The configuration authors Identity Platform, Google sign-in, Firebase Hosting, and the
scale-to-zero read service against the settled host `tracker.martcoca.com`. Real project,
region, site, service-account, image, and OAuth values remain protected plan/apply inputs.
The Google OAuth client secret will enter OpenTofu state, so the Founder must select a
protected encrypted backend before applying.
