## Decisions

The holder is in memory. Every new process fetches synchronously and refuses startup if any
required copy is absent; after startup, refreshes run concurrently every five minutes with
a five-second per-source timeout. A restart during a source outage therefore refuses rather
than silently manufacturing state, while a running process keeps its last verified copies.

The defaults are `https://tracker.martcoca.com/packets.json`,
`https://identity.martcoca.com/tenant-directory.json`, and
`https://identity.martcoca.com/agent-grants.json`. `PACKET_EXPORT_URL`,
`TENANT_DIRECTORY_URL`, `AGENT_GRANTS_URL`, `EXPORT_REFRESH_INTERVAL`, and
`EXPORT_FETCH_TIMEOUT` override them. Production endpoints must use HTTPS and may not carry
userinfo, query credentials, or fragments; plain HTTP is accepted only on loopback for the
offline fixtures. Responses are capped at 16 MiB.

Packet and tenant payloads are decoded with their existing readers after the shared envelope
check. T04 verifies and holds the agent-grants envelope but deliberately does not invent its
authorization payload model; E03 owns that contract before any grant can authorize a call.
Its `VerifiedCopy` seam returns defensive bytes and rechecks expiry for that future decoder.
The existing `/healthz` route now exposes safe per-export age, expiry, last-attempt,
last-success, and refresh-error metadata and returns unavailable when a required copy is
missing or stale. No route was added or removed.

## T03 image handoff and limits

T03 must place the compiled `tracker-web` binary, CA roots, and only the minimal runtime
files in the image. It must not place packet, tenant-directory, or agent-grants exports in
the image; it must not place a credential, compiler, module cache, or source there. The
binary needs outbound HTTPS to the configured public static objects and needs no export
credential. The old Cloud Run `PACKET_EXPORT_PATH` and `TENANT_DIRECTORY_PATH` environment
entries are ignored now and should be removed or replaced with URL/timing overrides when
T03 updates the unapplied plan.

No image, registry push, cloud resource, deployment, credential, real identity, or export
payload was created or changed. The real tracker packet object is not yet published, and
live Cloud Run startup against all three production endpoints remains for T03/the Founder
to prove after that static object and the deployment exist.
